# Git Branching Workflow — Simple Calculator

A demonstration project showcasing a **professional Git workflow** using Git Flow branching strategy, feature branches, pull requests, and merge conflict resolution.

## Objective

To implement and document an industry-standard Git-based version control workflow on a real (small) codebase.

## Tech Stack

- Python 3
- Git & GitHub
- GitHub Actions (for CI, see `.github/workflows`)
